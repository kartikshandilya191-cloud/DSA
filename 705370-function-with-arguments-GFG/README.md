# [Function With Arguments](https://www.geeksforgeeks.org/problems/function-with-arguments-1605762259/1)
## Easy
Given two integers a and b. The given&nbsp;input and its values are passed as arguments to the function argumentFunction. The argumentFunction is responsible to return (a+b). You need to write this function.
Examples: 
Input: a = 2, b = 3
Output: 5
Explanation: 2 + 3 = 5
Input: a = 7, b = 2
Output: 9
Explanation: 7 + 2 = 9
Constraints:1 ≤ a, b ≤ 10
