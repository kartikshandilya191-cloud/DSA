# [Function With No Arguments](https://www.geeksforgeeks.org/problems/function-with-no-arguments-1605703188/1)
## Easy
This problem has no input. You need to write a function to be named as helloFunction(). The function should only prints Hello followed by a new line.Examples:&nbsp;Input: None
Output: Hello
Explanation: There is no input. The function prints Hello everytime.
