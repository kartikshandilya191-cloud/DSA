# [Inverted Right Angle Triangle Pattern](https://www.geeksforgeeks.org/problems/inverted-right-angletriangle-1605691171--104349/1)
## Easy
Given an integer n, the task is to print an inverted right-angled triangle pattern using the * character. The pattern contains n rows, with the first row containing n stars and each subsequent row containing one fewer star.Examples:  Input: n = 5
Output:
************ ***
Explanation: Length of perpendicular and base of triangle is 5.Input: n = 3Output:*** ** *
Explanation: Length of perpendicular and base of triangle is 3.
